## clone, domain, workspace

$ desolate clone acme/app --no-domain
  read key: registered
  write key: registered (it asks you before every push)
cloned acme/app: 1 branch(es), default main, 0 LFS object(s); pushable.
next: desolate domain create <slug> --repo acme/app   (or, to a domain you have: desolate domain <slug> add --repo acme/app; or clone again with --domain <slug>)
fetching acme/app with the read key
[exit 0]

$ desolate domain create dev
created the domain dev ("dev").
next: desolate domain dev add --repo <owner>/<repo>
[exit 0]

$ desolate domain dev add --repo acme/app
acme/app is now in the domain dev: every workspace in it gets a checkout, borrowing the mirror's objects.
next: desolate up dev
[exit 0]

$ desolate up dev
