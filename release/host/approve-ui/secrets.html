Secrets

A secret's value is held in the root VM. A workspace only ever sees its name: the domain's proxy puts the value in its place on the way to the hosts you name, in the headers you name, and nowhere else. This page is the Mac's own, like the approval page: what you type here goes from this browser to the Mac and into the root's store, never through the dashboard.

Add a secret

Import a .env

Paste a project's .env, or choose the file. Its API keys become this domain's secrets, and you get back the same .env with each secret's name in place of its value, for the workspace. The values go from this browser to the Mac, as above; the plan shows none of them. What you change in the plan is remembered for this domain. From a terminal: desolate domain <domain> secret import <.env>.
