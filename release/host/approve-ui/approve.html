Nothing is waiting for your approval.

This is where a push, or an issue a workspace offers, stops until you say yes. One appears here, within a second, when:

  • you click Push on an offered branch on the dashboard,
  • you run desolate push in a terminal on this Mac,
  • you git push in the git VM (desolate git --open), or
  • you click Publish on an issue a workspace offered.
